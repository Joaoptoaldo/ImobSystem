# Sistema de Gerenciamento de Aluguéis

> Em desenvolvimento

## Sobre o Projeto

O **Sistema de Gerenciamento de Aluguéis** é uma aplicação web desenvolvida para auxiliar no gerenciamento de imóveis destinados à locação.

O objetivo do sistema é permitir o cadastro de clientes e imóveis, o gerenciamento das locações realizadas e a consulta das informações relacionadas aos imóveis e seus respectivos contratos.

Atualmente, este repositório contém a documentação inicial do projeto, incluindo o levantamento de requisitos e os diagramas utilizados na etapa de modelagem do sistema. A implementação da aplicação será desenvolvida nas próximas etapas.
